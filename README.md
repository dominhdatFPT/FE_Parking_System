# Parking Building Management Frontend

Frontend structure for the Parking Building Management System.

## Structure

- `src/app`: app shell, routes, and providers.
- `src/layouts`: layouts for Admin, Manager, Staff, and Driver screens.
- `src/features/admin`: system administrator features.
- `src/features/manager`: parking manager features.
- `src/features/staff`: parking staff operation features.
- `src/features/driver`: parking user/driver features.
- `src/features/parking`: shared parking availability and slot features.
- `src/features/auth`: authentication and authorization.
- `src/features/notifications`: admin/user/system notifications.
- `src/features/feedback`: feedback and support tickets.
- `src/features/ai-optimization`: smart parking allocation features.
- `src/docs/FRONTEND_STRUCTURE.md`: detailed module and function description.

Read `src/docs/FRONTEND_STRUCTURE.md` before implementing new screens.
